# Development references

## Bitwig Controller API

For the API 25 Javadoc, open Bitwig Studio 6.1.7 and choose Help → Documentation → Developer Resources. Look up the class or method named in the engineering notes. The [Bitwig controller extensions repository](https://github.com/bitwig/bitwig-extensions) also describes where to find the API reference. The [API dependency record](../dependencies/bitwig-api-25.properties) identifies the compile-time JAR.

## OXI E16

Consult the [E16 manual](https://docs.oxiinstruments.com/oxi-e16-manual/lua-scripting/) and the [OXI Remote worksheet](https://docs.google.com/spreadsheets/d/1Yccnrluv10QL_PauMmtCt64EtYjfSeZEXKrlrw8P24w/edit) for the manufacturer's documentation. The [M1 hardware record](hardware-tests/m1.md) documents which acknowledgement and command forms worked on E16 SW 1.3.1.
