## Scene independence and preservation — passed for tested assignments, 2026-11-23

**Documented expectation:** [OXI's manual](https://docs.oxiinstruments.com/oxi-e16-manual/lua-scripting/), reader lines 57–58, describes Remote Mode as directing knob/button events to the host instead of controlling the device's scenes/pages. Together with the fixed channel-1, USB-Port-1 CC/note mapping in the supplied Remote Guide, this supports a temporary mode that needs no uploaded scene or default mapping. That is an interpretation of the documented behaviour, not proof for all SW 1.3.1 settings. The current extension sends entry, label, ring and exit requests; it does not upload, edit, save or select an E16 scene. The entry ACK confirms Remote Mode entry; it contains no scene identity or settings checksum.

**Measured so far:** Encoder 1 sent the expected channel-1 relative CC 1 messages; Shift note 16 also appeared in an earlier log. Shutdown returned the E16 to its ordinary screen. On 2026-11-23 the user explicitly confirmed changing the normal scene's knob/button assignments, finding Remote Mode still worked, and finding those assignments preserved on exit. This supports independence from the tested scene mappings and the single-extension distribution approach. The report does not enumerate changed settings or supply per-encoder MIDI captures; preservation of every value/unsaved edit and all global setting combinations is not established by it.

**Reproducible procedure and broader coverage:** Use a disposable scene or a backed-up copy, recording its initial assignments and values. In normal mode, configure encoder 1 to a distinguishable CC/channel and push action, confirm its output, then enter Remote Mode with the existing extension. Confirm clockwise/counterclockwise turns produce channel-1 CC 1 relative deltas and press/release produce channel-1 note 0 on/off on USB Port 1. Confirm gestures do not also emit the original scene's messages on its selected destinations. Exit and check the original assignments, values and unsaved edits, as well as normal gesture behaviour. Repeat from a different scene/page and with differing output, disabled-control and acceleration settings; do not assume all global hardware settings are bypassed. Record any effect of Remote Mode gestures on normal scene values. The user report above establishes the initial changed-assignment/preservation result; the wider combinations and full encoder/button mapping remain coverage for later milestones.

**Protocol limitation:** The supplied Remote protocol provides no query to identify or validate a default scene, and no documented temporary scene upload/restore transaction. The tested assignments did not require such a workaround. If future tests expose scene dependence, investigate firmware behaviour with OXI before introducing scene writes or changing the single-extension distribution goal.
